# Repository workflows

- Use root workspace scripts for website tasks; consult `AGENTS.md` for current commands and paths.
- Preserve existing instructions and skills. Merge corrections rather than replacing files wholesale.
- Keep changes scoped to the request; do not add a backend, shared package, task orchestrator, or integration speculatively.
- Report only checks actually run. Documentation/configuration presence is not runtime validation.
- For derived projects, resolve business facts from confirmed input and repository evidence; leave unknowns explicit.
