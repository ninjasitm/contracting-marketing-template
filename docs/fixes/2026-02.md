## [2026-02-09] - Vitest Nuxt Runtime Mocks

### Fixed/Changed/Added

- **Issue**: Server handler tests failed due to Nuxt runtime imports and Vite/Vitest mismatches
  - **Root cause**: Test runner relied on Nuxt runtime modules without a Nuxt instance and incompatible tooling versions
  - **Solution**: Align Vite/Vitest versions, add Nuxt runtime mocks, and alias Nuxt composables for tests
  - **Files modified**: vitest.config.ts, test/server/contact/send-email.test.ts, test/utils/email/factory.test.ts, test/mocks/nuxt-app.ts, test/mocks/nuxt-config.ts, test/mocks/nuxt-error.ts, test/mocks/nuxt-router.ts, test/mocks/nuxt-head.ts, test/mocks/nuxt-ssr.ts, test/mocks/nuxt-vitest-app-entry.ts, test/mocks/nodemailer.ts, package.json, pnpm-lock.yaml
